# Supporting Information

This repository contains (1) Relaxed structures and structures along the polarization switching pathway (VASP CONTCAR format) of Al1−xBxN, Al1-xScxN, Ga1-xScxN alloys and 24 wurtzite derived compounds from our [previous publication](https://github.com/prashungorai/papers/tree/main/2023/polarization_switching_mechanism/SS-NEB-pathway/compound). (2) PBE band gap of all equilibrium structures and structures along the polarization switching pathway. (3) HSE06 band gap of equilibrium structures and structures with global minimum band gap along the polarization switching pathway.


This repository accompanies the paper "Dynamic Band Gaps During Polarization Switching in Wurtzite Ferroelectrics".
